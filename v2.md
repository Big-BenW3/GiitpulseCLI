# Lenear v2 — Future Improvements

> Goal: beat CodeRabbit and Greptile as the strong OSS AI reviewer.

## T-REX (Runtime Validation) — flagship v2

Spins up a sandbox environment, runs the code changes, writes targeted test cases, and provides **real logs or videos** of what broke.

- Ephemeral micro-VM (Fly.io/Modal/Firecracker) per review, clones diff branch
- Infers language/framework, installs deps, runs build
- LLM generates targeted test cases for changed files (bugs/security)
- Captures stdout/stderr, video of failing run, attaches to review payload
- Stored in `reviews.payload.trex: { logs, videoUrl, tests }` for dashboard

Why OSS advantage vs Greptile/CodeRabbit: not just static analysis — runtime proof.

## Other v2

- **GitHub OAuth** (Auth.js) + Email coexistence; v1 is Email/Resend only
- **PR integration**: GitHub App posts inline comments + check run with score
- **Auto-fix (`lenear fix --dry-run` → `lenear fix`)**: opt-in, applies `suggestion` patches with diff preview + confirm, limited to style/suggestions
- **Local-only mode**: Ollama provider for offline
- **Multi-model consensus**: Nvidia + Groq ensemble
- **Notifications**: Resend critical alerts + weekly digest (Resend wiring already in `web/src/lib/resend.ts`)
- **Dashboard polish**: final lime theme already, add severity donut, project filters, share links
- **Marketplace**: VS Code extension wrapping CLI

## Non-goals for v1

- Keep v1 as `lenear review` static analysis + dashboard history — no sandbox, no auto-fix.
